### What I keep coming back to

Looking at what I've actually shipped, the through-line isn't a framework — it's **state that has to stay correct**. A slot machine that must roll back cleanly when a spin fails halfway. An auction where a nomination draw has to be reproducible. An outreach tool that refuses to send until you've typed the confirmation phrase yourself.

I like problems where the rules are the interesting part, and where the safe thing and the obvious thing aren't the same thing.

## Featured projects

| Project | What it does | Stack |
| :--- | :--- | :--- |
| **[Auction Room](https://github.com/xDivyanshx/AuctionWithFriends)** | A live auction room for Fantasy Premier League drafts. Runs the whole lifecycle — weighted nomination draws, bidding, squad validation, swaps and live standings — against PostgreSQL and the official FPL API. | `ASP.NET Core` `.NET 10` `EF Core` `PostgreSQL` `React` |
| **[NearLens Teleprompter](https://github.com/xDivyanshx/Nearlens-Teleprompter)** | A privacy-first teleprompter that floats your script as close to the webcam as it can. No camera, no microphone, no account, no uploads. Ships as both a Chromium extension and a native WPF overlay. | `WPF` `.NET 10` `Chromium Extension` `JavaScript` |
| **[EGM](https://github.com/xDivyanshx/EGM)** | A simulation of the core control module inside an electronic gaming machine. Transactional state updates with rollback, hardware simulation and audit logging — with a CLI *and* a React dashboard sharing one core, to show the logic is interface-agnostic. | `C#` `.NET 8` `React` |
| **[Cold Mail Sender](https://github.com/xDivyanshx/EmailSender)** | A local-only Gmail outreach workspace: OAuth, threaded follow-ups, campaign state in plain JSON, no database. Deliberately never sends on its own — you preview, pick recipients, and type a confirmation phrase first. | `ASP.NET Core` `.NET 10` `React` `Gmail OAuth` |
